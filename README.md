# AI Major Planning

A working space for Charles and Chris to develop ideas for a possible new undergraduate major
in the School of Engineering & Technology at UW Tacoma.

> **Status:** Early brainstorming. Nothing here is a proposal yet.

## The question we're exploring

What should a new program look like that prepares students to build software in a world where AI
is part of how software is designed, written, and shipped?

The shape is still open. Options on the table include:

- A standalone **AI** major
- A combined **AI / Software Development** major
- A track or concentration within an existing degree

Choosing among these is one of the first things to settle (see
[open-questions.md](open-questions.md)).

## How this repo is organized

| Path | What goes there |
| --- | --- |
| [`ideas/`](ideas/) | One file per idea: a course, a track, a theme, a pedagogical approach. Start from [`ideas/_template.md`](ideas/_template.md). |
| [`research/`](research/) | Peer programs, industry input, accreditation and institutional notes. |
| [`meetings/`](meetings/) | Agendas and notes, one file per meeting, named `YYYY-MM-DD-topic.md`. |
| [`open-questions.md`](open-questions.md) | Questions we haven't answered yet. |
| [`decisions.md`](decisions.md) | What we've agreed on, when, and why. |

## How we work together

- **Anyone can add an idea.** Copy the template, give it a short descriptive filename, and fill
  in what you have. Half-formed ideas are welcome; mark them as such.
- **Disagreements go in the idea file.** Add a "Discussion" section with each person's view rather
  than overwriting.
- **When something is settled,** record it in `decisions.md` with the date and reasoning, and
  update or close the related open question.
- **Small, frequent commits** to `main` are fine for now.
